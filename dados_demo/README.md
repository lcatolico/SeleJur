# Dados Demo - SeleJur

Este pacote cria um cenario simples para demonstrar a Fase 1 do SeleJur.

## Cenario

Um recrutador de uma Procuradoria Municipal publica um Seletivo para Assessor Juridico. Quatro candidatos se inscrevem. O recrutador analisa o painel, ve a triagem assistida e convoca dois candidatos para pre-entrevista em video.

## Arquivos

- `recrutadores.csv`: conta demo do recrutador.
- `candidatos.csv`: candidatos demo.
- `seletivos.csv`: Seletivo demo com inscritos e fase de video.
- `roteiro_demo.md`: passo a passo para apresentar o produto.

## Como usar

1. Crie ou abra a planilha usada pelo app.
2. Copie os dados dos CSVs para as abas correspondentes.
3. Rode o app.
4. Entre como recrutador demo.
5. Abra "Meus Seletivos" e depois "Ver inscritos".
